# Holger Wiedemann

Freelance iOS expert and mobile architect from Germany. I build mobile solutions that people enjoy using, with solid architecture underneath.

I have been developing for mobile platforms since Apple released the first iPhone SDK in 2008, as developer, lead and architect. My projects range from apps for major retail and drugstore chains and finance and pension apps to AR prototypes with AI-based image recognition and IoT solutions for fire safety technology.

Industries I have worked in: retail, banking, insurance and pensions, healthcare and diagnostics, automotive, fire safety, culture and professional networking.

## What I do

- **Mobile architecture and technology consulting:** native, cross-platform, hybrid or web? From projects with different approaches and from comparing them for clients, I know that the right choice depends on more than technology: existing know-how in the team, UX compared to platform conventions, effort for OS updates and dependency on third parties.
- **Mobile development with a focus on UX:** native iOS with Swift, SwiftUI and UIKit, as well as cross-platform, hybrid and web-based apps.
- **Code reviews and security analysis:** examining apps, systems, interfaces and devices for vulnerabilities and technical issues, down to the protocol level.
- **Device integration and protocols:** Bluetooth, USB, serial interfaces, network and proprietary protocols.

AI coding agents are part of my everyday toolbox, used with clear rules for confidentiality and code quality.

## Open source

Swift packages, all built with Swift 6 and strict concurrency:

- [swift-keychain-kit](https://github.com/wiedem/swift-keychain-kit): type-safe Keychain API for iOS and macOS, with Secure Enclave and CryptoKit support
- [app-entitlements](https://github.com/wiedem/app-entitlements): type-safe runtime access to app entitlements on all Apple platforms, reading code signatures without private APIs
- [fullscreen-cover](https://github.com/wiedem/fullscreen-cover): full-screen SwiftUI modals with any transition and async present and dismiss
- [motion-effects](https://github.com/wiedem/motion-effects): parallax effects for SwiftUI, without motion permission prompts
- [enum-case-labeling](https://github.com/wiedem/enum-case-labeling): Swift macro that generates case labels for enums with associated values
